# 🛍️ Estilo Livre — Loja Virtual

**Estilo Livre** é uma loja virtual de moda urbana desenvolvida com HTML e CSS. O projeto apresenta uma interface moderna e responsiva, com páginas dedicadas ao cadastro de usuários, exibição de produtos e contato com o atendimento.

---

## 📁 Estrutura do Projeto

- `index.html` — Página inicial  
- `cadastro.html` — Formulário de cadastro  
- `produtos.html` — Galeria de produtos com campo de pesquisa  
- `falecomigo.html` — Página de contato com e-mail e telefone  
- `style.css` — Estilos globais  
- `assets/` — Imagens e ícones do projeto  

---

## 🖼️ Funcionalidades

- ✅ Layout responsivo com Flexbox  
- ✅ Galeria de produtos com 6 seções (2 por linha)  
- ✅ Campo de pesquisa para filtrar produtos  
- ✅ Ícones personalizados para contato  
- ✅ Favicon na aba do navegador  
- ✅ Rodapé com créditos do desenvolvedor
